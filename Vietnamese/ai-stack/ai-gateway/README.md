# AI Gateway

**AI Gateway** là cổng kết nối tập trung giúp bạn tích hợp nhiều AI model từ các nhà cung cấp khác nhau (OpenAI, Google, Deepseek...) thông qua một endpoint duy nhất — giảm độ phức tạp khi chuyển đổi model, hỗ trợ giám sát tập trung, tối ưu chi phí và bảo mật dữ liệu.

***

## Tổng quan

| Nhóm tính năng | Mô tả |
|---|---|
| **Đa mô hình (Multi-LLM)** | Tích hợp linh hoạt nhiều LLM từ nhiều provider qua một cổng kết nối duy nhất |
| **Giám sát** | Theo dõi hiệu suất và hoạt động qua metrics và logs, bao gồm cả các chỉ số latency chi tiết |
| **Kiểm soát truy cập** | Quản lý **Authentication Token** và đặt giới hạn Rate theo số request hoặc số token |
| **Tối ưu chi phí** | Caching giúp giảm số request tới model, tiết kiệm chi phí và cải thiện tốc độ phản hồi |
