# Dòng lệnh (CLI)

> Công cụ AI Coding chạy bằng dòng lệnh (terminal) — khai báo Base URL và API key qua biến môi trường. Phù hợp cho lập trình viên, và cho người dùng **Linux / WSL**.

Trước khi cài, xem [Điều kiện cần](../bat-dau.md).

{% hint style="warning" %}
Mỗi trang bên dưới có **tab riêng cho PAYG và Token Plan** ở phần cấu hình. Xác định loại dịch vụ của bạn trước (theo nơi bạn lấy key), rồi chỉ copy từ tab đó — key và Base URL lệch loại dịch vụ sẽ trả về `401 Unauthorized`.
{% endhint %}
