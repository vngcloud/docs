# Payment History

The **Payment History** page in vConsole records all activities related to invoice payments and GreenNode Service usage fee payments for the logged-in account. This allows users to review and check activities related to their account in the most intuitive way.

Access the **Payment History** page [**here.**](https://dashboard.console.greennode.ai/payment-history)

On the **Payment History** page, users will see the main data table, which includes the following components:

#### **1. Search toolbar** <a href="#paymenthistory-1.searchtoolbar" id="paymenthistory-1.searchtoolbar"></a>

***

**Search payment history using multiple criteria:**

* **Payment gateway:** Search payment history by payment gateway. GreenNode Service currently supports 3 main payment gateways:
  * Momo payment: Pay via the Momo app
  * ZaloPay payment: Pay via the ZaloPay app
  * Credit balance: Pay via the Credit wallet, managed by GreenNode Service
* **Payment time:** Search by day
* **Keyword:** Search by _Transaction ID / Transaction details_

_Finally, click the **"Magnifying glass"** icon to view the search results based on the criteria above._

**Export reports based on search criteria:**

_To export payment history data:_

* Click the **"Export report"** icon next to the **"Magnifying glass"** icon to export the full payment history based on the search results.
* Supported format: .pdf
* Save location: By default, the file is saved to the "Downloads" folder or according to your web browser settings.

#### **2. Search results** <a href="#paymenthistory-2.searchresults" id="paymenthistory-2.searchresults"></a>

***

Search results are displayed based on the criteria applied in the "Search toolbar" and include the following key information:

* **Transaction ID:** Identifier of each transaction
* **Payment type:** The purpose of the payment activity, including:
  * Payment service
  * Payment bill
  * Buy Bandwidth
  * Deposit
  * Deposit Trial
  * Advanced
* **Payment gateway:** There are 3 main payment gateways: **Momo** (pay via the Momo wallet), **ZaloPay** (pay via the ZaloPay wallet), and **Credit balance** (pay via the Credit wallet managed by GreenNode Service)
* **Payment date:** Date the transaction was made
* **Details:** Detailed description of the transaction, which may include service configuration information or system activities such as auto renew, etc.
* **Amount:** Total amount of the payment, in VND
