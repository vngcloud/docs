# S3 Explorer

### Overview

S3 Explorer is a desktop S3 client for Windows, macOS and Linux. It lets you browse buckets, upload and download objects, and preview images, video, audio and text files. It is free to use with up to 5 connection profiles.

To connect S3 Explorer to vStorage, you need your vStorage S3 key pair and the endpoint of your region. For details, see Integrate S3 Explorer with vStorage.
