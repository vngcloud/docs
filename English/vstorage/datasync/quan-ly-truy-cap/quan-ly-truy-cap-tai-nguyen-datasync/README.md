# Managing Access to DataSync Resources

### **Overview**

**IAM User Accounts** are representative accounts used to interact with GreenNode through the Portal UI. A user account at VNG includes authentication credentials (username and password) and is, by default, set to a state with no access permissions. These user accounts do not exist independently; they belong to a single root user account and come at no cost.

If your business has many members who need access to GreenNode, do not share the root user account's security credentials. VNG recommends creating a user account for each of these members under your root user account, so you can grant different permissions to each user account.
