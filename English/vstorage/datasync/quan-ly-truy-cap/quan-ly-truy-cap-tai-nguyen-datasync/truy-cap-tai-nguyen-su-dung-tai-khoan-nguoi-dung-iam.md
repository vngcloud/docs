# Access Permissions and Working Through IAM

To access your resources on the DataSync storage service, use the DataSync Portal. For the DataSync Portal, you can log in with either the Root user account or an IAM User Account. If you do not have an IAM user account yet, refer to [IAM User Account](../quan-ly-tai-khoan-truy-cap-datasync/tai-khoan-nguoi-dung-iam/).

Follow the steps below to log in to DataSync with an IAM user account:

1. Go to the DataSync sign-in page: [https://signin.vngcloud.vn](https://signin.vngcloud.vn).
2. On the main sign-in page, select **LOG IN WITH IAM USER ACCOUNT**.
3. Enter the **email** address of the Root user used when registering the GreenNode account.
4. Enter the **username** and **password** of the IAM user account created in the vIAM system.
5. Select **LOG IN WITH IAM USER ACCOUNT**. If you previously logged in as an IAM user account in this browser, the browser may remember the IAM user account address; if so, you will see the screen shown in step 3. After you sign in successfully, the DataSync home screen shows which account type you are using (Root user account or IAM user account).
6. After signing in successfully, you can access and use the DataSync features on the resources you are authorized for. For the supported features, refer to [Features of DataSync](https://docs.greennode.ai/vstorage/datasync/cac-tinh-nang-cua-datasync.md). If your IAM user account has not been granted permission to perform DataSync features on resources, refer to [IAM User Account](../quan-ly-tai-khoan-truy-cap-datasync/tai-khoan-nguoi-dung-iam/).
