# Access Control

To secure access to DataSync, we use Identity and Access Management (IAM) as our authorization solution. IAM is an effective authorization solution for securing access to data stored on DataSync. It provides the features and functions needed to establish a user's identity and their permissions on each DataSync resource. With IAM, a business can ensure that only users with the necessary access rights can access their data, protecting it from unauthorized access.

Specific benefits of using IAM to secure data on DataSync:

* **Ensures only authorized users can access data:** IAM lets businesses create and manage access policies for each DataSync resource, so only users who need access to specific data can reach it.
* **Prevents unauthorized access:** IAM provides strong authentication and authorization features that help prevent unauthorized access to data.
* **Reduces the risk of data breaches:** by using IAM, businesses can reduce the risk of breaches, since IAM protects data from unauthorized access.
